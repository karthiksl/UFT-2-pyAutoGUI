# SAMPLE_TEST_000001 — Offline E2E Fixture

A self-contained dry-run fixture for the **UFT → PyAutoGUI** migration
framework.  Every framework layer (OR loader, finder, actions, OCR, waits,
retries, reporting) is exercised against synthetic PNG screens without
connecting to Citrix or Epic.

## Step 1 — Generate mock screen PNGs

Run once (or whenever you change `generate_mock_screens.py`):

```bash
python fixtures/sample_uft/generate_mock_screens.py
```

Expected output:
```
Generating mock screens …
  saved → fixtures/sample_uft/screens/app_frame.png
  ...
  crop  → automation/assets/images/sample/coverage_effective_date_field.png
Done.  All PNGs written.
```

> **Why a script instead of committed PNGs?**  
> Committed binaries bloat git history and become stale when you tweak the
> screen design.  The generator is deterministic — running it twice produces
> identical files.

---

## Step 2 — Start the screen player

In a dedicated terminal:

```bash
python fixtures/sample_uft/screen_player.py
```

The window opens at `(0, 0)` showing `login.png`.

| Key / action | Effect |
|---|---|
| `F8` | Advance to next screen |
| Click **Login button** | Login → Home (auto-advance) |
| Click **Coverage tab** | Home → Coverage (auto-advance) |
| `Escape` | Quit |

> **macOS Retina note:** tkinter uses logical pixels (half the physical
> resolution on 2× screens).  PyAutoGUI operates in physical pixels.
> Either run the test at 1× (System Preferences → Displays → Scaled →
> "Looks like 1280×800") or set `PYAUTOGUI_SCALE=2`.

## Design decisions

| Decision | Reason |
|---|---|
| Pillow-only generation (no OpenCV) | Avoids heavy dependency for a fixture-only script |
| tkinter screen player | Stdlib; no pygame required |
| Fixed 1280×800 | Matches a typical laptop resolution; avoids Retina complications |
| Object PNGs are tight crops | Matches how `core/finder.py` uses template matching inside bounded regions |
| `screen_player.py` responds to real mouse clicks | Lets the actual `actions.click()` call drive the transition — not mocked |
